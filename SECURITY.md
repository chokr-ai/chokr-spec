# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting instead:
<https://github.com/chokr-ai/chokr-spec/security/advisories/new>

Include the document or vector, the result you got and the result you expected. A case where the checker accepts a
tampered ledger, a bad signature or an invalid document is a security bug, so please report it even if it looks like
a quirk of the format.

## Supported versions

The project is in alpha. Only the latest release receives fixes.
